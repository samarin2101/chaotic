# Chaotic-AUR Installer

Этот скрипт позволяет быстро подключить репозиторий **Chaotic-AUR** в Arch Linux и системах на его основе.  
Пользователю не нужно ничего настраивать — достаточно просто запустить готовый скрипт.

---

## 🖥 Поддерживаемые системы

Скрипт работает в системах, основанных на **Arch Linux**:

- Arch Linux  
- EndeavourOS  
- CachyOS  
- Garuda Linux (уже имеет Chaotic-AUR по умолчанию)  
- Manjaro (неофициально)

> Если ваша система использует пакетный менеджер **pacman**, скрипт подходит.  
> Для Manjaro использование репозитория Chaotic-AUR не является официально поддерживаемым, поэтому будьте внимательны при установке пакетов.

---

## 🚀 Как использовать скрипт

1. Сохраните скрипт в любую удобную папку.  
2. Откройте **терминал в той же папке**, где находится скрипт.  
   - В графическом файловом менеджере это обычно делается **правой кнопкой мыши → «Открыть терминал здесь»**.
3. Запустите скрипт:

```bash
./chaotic-install.sh
