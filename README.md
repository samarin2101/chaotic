# Chaotic-AUR Installer

Этот скрипт позволяет быстро подключить репозиторий **Chaotic-AUR** в Arch Linux и системах на его основе.  
Пользователю не нужно ничего настраивать — достаточно просто запустить готовый скрипт.

---

## 🖥 Поддерживаемые системы

Скрипт работает в системах, основанных на **Arch Linux**:

- Arch Linux  
- EndeavourOS  
- CachyOS
- Manjaro (неофициально)
- Garuda Linux (уже имеет Chaotic-AUR по умолчанию)

> Если ваша система использует пакетный менеджер **pacman**, скрипт подходит.

---
